# AI Telegram Bot Optimizer

This is a Python-based automation project designed to optimize Telegram bot workflows, Google Sheets API usage, IMAP email parsing, and backend task handling.

## Features

- Telegram bot workflow structure
- Google Sheets API caching
- IMAP email parsing helpers
- Async queue handling
- Retry and error handling
- Backend architecture examples

## Tech Stack

- Python
- Telegram Bot API
- Google Sheets API
- IMAP
- SQLite
- AsyncIO
